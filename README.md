# Extended HUD – FS25 / LS25

🇩🇪 Deutsch | 🇬🇧 English below

## Was macht der Mod?

**Extended HUD** erweitert das F1-Hilfefenster im Landwirtschafts-Simulator 25, damit dort mehr Tastenbelegungen gleichzeitig angezeigt werden. Kein Schnickschnack – einfach mehr Übersicht, welche Tasten du gerade drücken kannst.

## Installation

1. Lade die Datei **`FS25_ExtendedHUD.zip`** unter [Releases](../../releases) herunter.
2. Kopiere die ZIP-Datei **ungeöffnet** in deinen Mod-Ordner:
   `Dokumente\My Games\FarmingSimulator2025\mods`
3. Spiel starten, Mod im Savegame aktivieren – fertig.

> ⚠️ Bitte **nicht** den grünen „Code → Download ZIP“-Button benutzen. Diese ZIP hat einen falschen Namen und eine zusätzliche Ordnerebene und funktioniert im Spiel nicht.

## Fehler gefunden?

Melde ihn gerne unter [Issues](../../issues) oder auf meinem Discord.

## 🇬🇧 English

**Extended HUD** expands the F1 help window in Farming Simulator 25 so it shows more key bindings at once.

### Installation

1. Download **`FS25_ExtendedHUD.zip`** from [Releases](../../releases).
2. Put the ZIP file (**do not unzip**) into your mods folder:
   `Documents\My Games\FarmingSimulator2025\mods`
3. Start the game and enable the mod in your savegame.

> ⚠️ Do **not** use the green "Code → Download ZIP" button – that archive will not work in-game.
